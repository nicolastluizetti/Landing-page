# Presença Digital

Landing page comercial para oferecer:
1. Landing pages
2. E-mail profissional
3. HTTPS/SSL
4. Configuração do Perfil da Empresa no Google

## Como usar

1. Abra `script.js`.
2. Altere a constante `WHATSAPP` para o número real.
3. Edite o nome "Presença Digital" no `index.html`.
4. Substitua os projetos demonstrativos pelos seus projetos.
5. Abra `index.html` no navegador.

## Estrutura

- index.html
- style.css
- script.js
